# RadioBox F1

## Propósito del proyecto

RadioBox F1 es una página web dedicada a la historia de la Fórmula 1. El objetivo del proyecto es presentar de manera simple y visual información sobre diferentes temporadas, autos y contenidos relacionados con la categoría.

La página fue desarrollada como proyecto de pre-entrega para un curso de Front End, utilizando los conocimientos adquiridos de **HTML y CSS**.

## Contenido

La página incluye:

- Información sobre RadioBox F1.
- Sección sobre la historia de la Fórmula 1.
- Imágenes de autos de distintas épocas.
- Contenido multimedia mediante videos de YouTube.
- Menú de navegación interno.

## Tecnologías utilizadas

- HTML
- CSS

## Autor

Proyecto realizado para la pre-entrega del curso de Front End.
